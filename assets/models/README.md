# Modelos 3D

Aquí se integrarán los tres modelos 3D definitivos requeridos por la rúbrica.

Para cada modelo registrar en el README principal:

- Nombre del recurso
- Autor
- Sitio de origen
- URL
- Licencia
- Cambios u optimización realizada
- Tamaño final del GLB

Objetivo: mantener cada GLB por debajo de 5 MB.
